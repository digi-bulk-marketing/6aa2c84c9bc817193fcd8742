## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2c84c9bc817193fcd8742/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **TRUECALLER FILTER** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2c84c9bc817193fcd8742/releases/latest) and reinstall.
